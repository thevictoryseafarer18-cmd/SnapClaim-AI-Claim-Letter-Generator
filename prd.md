# SnapClaim: PRD
**Problem:** Policyholders under-describe damage and use the wrong terms, so they settle for less.
**User:** a non-expert filing an auto, home or renters claim.
**Requirements:** (1) landing page with CTA; (2) 4-step wizard with progress bar; (3) drag-and-drop upload with validation; (4) minimal form: insurance type, date, one-sentence description; (5) vision analysis returning structured JSON (items, severity 1–5); (6) letter with placeholders, reference number, itemized damages, inspection request, rights-reservation clause; (7) editable letter; (8) PDF export; (9) friendly error with retry; (10) skeleton loading.
**Non-goals:** legal advice, claim-value estimates.
